## About this sample

This is a **sample article**. It is not real content. It shows how an article is displayed and which formatting you can use when you write your own. Delete this article, and its entry in `data/articles.json`, when you are ready.

## Headings

Use `##` for a main heading and `###` for a smaller heading under it. Do not use bold text as a heading, because screen-reader users move through a page by its headings.

### A smaller heading

Paragraphs are separated by one empty line. You can write in *italics* or **bold** when needed.

## Lists and quotations

- A bullet list starts each line with a dash and a space.
- Each item is one line.

1. A numbered list starts each line with a number and a full stop.
2. Numbers are added in order.

> A quotation starts with a greater-than sign. Always name the source of a quotation straight after it.

## Writing in Odia script

To mark a passage in another language, put it inside double square brackets with the language code first, like this: the archive's Odia name [[or: କଥାଲଥା]]. This lets screen readers pick the right voice.

## Links and pictures

A link looks like [this link to the archive home page](index.html). A picture is added with an exclamation mark, a short description in square brackets (the alt text), and the file name in round brackets. Always write the description.

## Sources

End every article with a list of sources, and say clearly which statements are unverified.
